# Verification results

`backend-verification.json` and `backend-postgres-verification.json` record isolated acceptance checks and local performance measurements. The PostgreSQL file is historical evidence unless regenerated against a disposable PostgreSQL database. These files are not production uptime or usability evidence.

Run the acceptance scripts under `backend/tests`; see [test instructions](../../backend/tests/README.md). The backend verification script updates the corresponding report here.

The revised SRS account checks and Android emulator observations are recorded in [Accounts](ACCOUNTS.md).
